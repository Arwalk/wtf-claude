## Findings considered and rejected

- **Incremental transcript cache**: measured about 21 ms for 20 MB of
  transcripts, roughly 1 s/GB per run. The README already documents the
  trade-off. Not worth the complexity.
- **Lock timeout leaves an already-expired context for the fallback fetch**
  (`internal/cache/cache.go:179-190`, ctx from `main.go:325`): needs the lock
  holder to be stuck longer than its own 10 s HTTP timeout (e.g. a suspended
  process). Too rare to matter.
- **Cache dir fallback to `os.TempDir()` when `$HOME` is unresolvable**
  (`internal/cache/cache.go:41`): only without a home dir, and the cache holds
  usage and plan data, no credentials and no personal data.
- **`--token` visible in `ps`**: the README warns about it and recommends the
  stored login.
- **Goroutines in `collect` writing `status` concurrently**
  (`main.go:356-375`): they write different fields, and `go test -race` is
  clean.
- **"`testdata/usage.json` is empty"**: a `wc -l` artefact. The file is one
  2.2 KB line with no trailing newline.
- **`weekly_scoped_shares` in the usage response is ignored**: it restates
  the scoped limit's percent (35/50 of weekly ≈ the 69-70% shown).
